# 📰 Newsers - Yangiliklar Portali

**Newsers** — Django asosida qurilgan zamonaviy o'zbek yangiliklar portali.

## 🌟 Loyiha haqida

Newsers — foydalanuvchilarga turli kategoriyalardagi yangiliklarni o'qish, izoh qoldirish va obuna bo'lish imkonini beruvchi to'liq funksional yangiliklar sayti.

## 🚀 Asosiy imkoniyatlar

- 📌 Yangiliklar kategoriyalar bo'yicha ajratilgan
- 👁️ Ko'rishlar soni va o'qish vaqti ko'rsatiladi
- 💬 Izoh qoldirish tizimi
- 🔍 Qidiruv funksiyasi
- 🌤️ Real vaqt ob-havo ma'lumoti
- 📧 Email orqali obuna bo'lish
- 📬 Aloqa formasi (xarita bilan)
- 📈 Trending yangiliklar
- 🔥 Eng ko'p ko'rilgan maqolalar
